# Loan Portfolio Analysis Dashboard

An interactive Power BI dashboard analyzing **39.7K loan applications** to understand loan performance and credit risk.

## Key Features
- Loan portfolio KPIs and performance analysis
- Loan status, grade, purpose, and monthly trend analysis
- Credit-risk and charge-off analysis
- Interactive dashboard visuals

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Project File
Open `Bank Dashboard.pbix` in Microsoft Power BI Desktop to explore the dashboard.
